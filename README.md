# Higher Level Programming  
Holberton School — Front-End Foundations

This repository contains multiple projects focused on building strong front-end development fundamentals. You will work through advanced HTML structure, advanced CSS styling, and JavaScript basics using Node.js. Each project builds toward a deeper understanding of modern web development practices.

---

## 📂 Projects Included

### 1️⃣ HTML Advanced
A complete semantic HTML layout built without CSS or JavaScript. Focuses on structure, accessibility, and clean markup.

#### Learning Objectives
- Semantic HTML and why it matters  
- Structuring a full webpage using only HTML  
- Using header, nav, section, article, aside, footer  
- Embedding images, videos, and iframes  
- Using lists, tables, and forms  
- Accessibility through proper markup  
- Validating HTML with W3C tools  

#### Requirements
- Only HTML allowed  
- No inline CSS or JS  
- W3C-compliant markup  
- All files end with a new line  
- Allowed editors: vi, vim, emacs  

---

### 2️⃣ CSS Advanced
Advanced styling techniques for modern, responsive layouts.

#### Learning Objectives
- CSS variables (custom properties)  
- Transitions and animations  
- Transform functions (scale, rotate, translate)  
- Flexbox and Grid layout systems  
- Pseudo-classes and pseudo-elements  
- Component-based styling  
- Responsive design principles  
- Organizing CSS for large projects  

#### Requirements
- External `.css` files only  
- No inline styles  
- W3C-compliant CSS  
- All files end with a new line  
- Allowed editors: vi, vim, emacs  

---

### 3️⃣ JavaScript Warm Up
Introduction to JavaScript using Node.js. Covers variables, control flow, loops, functions, dictionaries, and file importing.

#### Learning Objectives
- Why JavaScript is amazing  
- Running JavaScript scripts with Node.js  
- Creating variables and constants  
- Differences between `var`, `let`, and `const`  
- JavaScript data types  
- Using `if` and `if…else`  
- Writing comments  
- Assigning values to variables  
- Using `while` and `for` loops  
- Using `break` and `continue`  
- Functions and return values  
- Variable scope  
- Arithmetic operators  
- Manipulating dictionaries (objects)  
- Importing files with `require`  

#### Requirements
- First line of every file must be:  
#!/usr/bin/node

- Node.js 14.x  
- semistandard-compliant code (Standard + semicolons)  
- All files must be executable  
- All files end with a new line  
- Allowed editors: vi, vim, emacs
