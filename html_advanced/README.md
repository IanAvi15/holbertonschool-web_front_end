# HTML Advanced

A project focused on learning how to structure web pages using HTML5 semantic tags. No CSS or styling is used — the goal is understanding proper HTML structure and semantics.

---

## Learning Objectives

By the end of this project, you should be able to explain:

- Which guidelines to follow for HTML
- How to create the skeleton of an HTML5 page
- How to use semantic HTML tags to structure a web page
- When to use `div` vs `span`
- The semantic value of `header`, `main`, `footer`, `article`, `nav`, `section`, and `aside`
- How to use headings correctly and why hierarchical order matters
- How to make lists in HTML
- The differences between media formats (SVG, GIF, PNG, JPG)
- How to structure data in a table
- How to integrate video and audio in a webpage
- How to embed external content
- How to correctly structure an HTML page

---

## Requirements

- Code must be W3C compliant and validate with the W3C Validator
- `Techium` is the name of the company used across all webpages in this project
